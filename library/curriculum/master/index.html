Master Curriculum: 40 Weeks¶

This is the comprehensive reference plan — the full day-by-day schedule covering every topic, case study, and scenario. New here? Start at training/START_HERE.md. For shorter curated paths, see paths.md.

All DevOps technical topics, case studies, and interview scenarios in a single day-by-day schedule. Designed for 60-90 minutes per day, 5 days per week.

Total time: ~37 weeks (~185 sessions) Daily budget: 60-90 minutes Schedule: Monday-Thursday = primary topics, Friday = review + supplement Tracks covered: Foundations, Containers, K8s Core, Helm, Observability, Incident Response, Advanced Platform, SRE & Reliability, Cloud & FinOps, Infrastructure, Modern CLI, Professional Skills

How to Use This Curriculum¶

  1. Follow the days in order. Each day builds on previous work.
  2. Use the exit criteria. Don't advance until the criteria are met.
  3. Friday supplements are not optional. They build skills that accelerate everything else.
  4. Use spaced repetition. After each topic, review its flashcards. Run make run-training-session weekly.
  5. Track progress. Use make report-training-progress to see coverage and weak areas.

If you fall behind, skip to the next Monday and backfill Fridays. The technical sequence matters more than completeness.
