# ^^^ ROOT CAUSE: switch uses src-mac hashing
# Since the server bond presents a single MAC address (0a:1b:2c:3d:4e:50),
# ALL traffic from any source host destined to the server hashes based on
# that source's MAC. If the upstream router has one MAC, all traffic goes
# to one link.
