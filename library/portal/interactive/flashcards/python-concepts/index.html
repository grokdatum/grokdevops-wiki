🟢 Easy (55)¶

1. if / elif / else

Show answer x = 10
if x > 20:
print("big")
elif x > 5:
print("medium") # ← this runs
else:
print("small")

Conditions are evaluated top-to-bottom; first True branch wins. elif and else are optional.

2. for loop

Show answer for name in ["alice", "bob", "carol"]:
print(name.upper())

Iterates over any iterable: lists, strings, dicts, files, generators, range().

3. while loop

Show answer n = 5
while n > 0:
print(n)
n -= 1

Runs as long as the condition is True. Use break to exit early.

4. break

Show answer for n in range(100):
if n > 4:
break
print(n) # prints 0 1 2 3 4

Exits the innermost loop immediately.

5. continue

Show answer for n in range(5):
if n == 2:
continue
print(n) # prints 0 1 3 4

Skips the rest of the current iteration, jumps to the next one.

6. pass

Show answer class NotYet:
pass # placeholder — class body can't be empty

def todo():
pass # same for functions

Does nothing. Used as a syntactic placeholder.

7. def (function definition)

Show answer def greet(name):
return f"hello, {name}"

print(greet("alice")) # hello, alice

Functions are first-class objects — you can pass them, return them, store them.

8. lambda (anonymous function)

Show answer square = lambda x: x ** 2
print(square(5)) # 25

sorted(["bob", "alice"], key=lambda s: len(s))
# ['bob', 'alice']

Single-expression functions. No statements, no multi-line.

9. return

return a + b

Sends a value back to the caller and exits the function. Without return, function returns None.

12. try / except

Show answer try:

except ValueError as e:
print(f"bad input: {e}")

Catch specific exceptions. Avoid bare except: — always name the exception type.

13. raise

Show answer def divide(a, b):
if b == 0:
raise ValueError("cannot divide by zero")
return a / b

Raise an exception explicitly. raise without args re-raises the current exception in an except block.

14. assert

Show answer def avg(nums):
assert len(nums) > 0, "empty list"
return sum(nums) / len(nums)

Raises AssertionError if condition is False. Disabled with python -O. Use for sanity checks, not input validation.

15. with (context manager)

Show answer with open("file.txt") as f:
data = f.read()
# f is automatically closed here

Guarantees cleanup (close, unlock, etc.) even if an exception occurs. Calls __enter__ and __exit__ under the hood.

16. as (aliasing)

Show answer import numpy as np # module alias
with open("f") as fh: # bind context manager result
except KeyError as e: # bind exception to name

as binds a name in import, with, and except statements.

17. in / not in (membership)

Show answer print(3 in [1, 2, 3]) # True
print("x" not in "hello") # True
print("key" in {"key": 1}) # True (checks keys)

Works on lists, tuples, sets, dicts (keys), strings (substring).

18. is / is not (identity)

Show answer x = None
if x is None:
print("nothing here")

b = a
print(a is b) # True (same object)

20. None

Show answer def find(lst, target):
for item in lst:
if item == target:
return item
return None # explicit "not found"

result = find([1,2,3], 99)

print("not found")

Python's null. There is exactly one None object. Always test with is None, not ==.

21. f-string (formatted string literal)

32. zip()

33. map() and filter()

Show answer nums = [1, 2, 3, 4, 5]

list(map(str, nums)) # ['1','2','3','4','5']
list(filter(lambda x: x>3, nums)) # [4, 5]

Both return lazy iterators. Usually prefer comprehensions:
[str(n) for n in nums]
[n for n in nums if n > 3]

34. any() and all()

Show answer nums = [2, 4, 6, 7, 8]
any(x > 5 for x in nums) # True (at least one)
all(x > 0 for x in nums) # True (every one)
all(x % 2 == 0 for x in nums) # False (7 is odd)

Short-circuit: any() stops at first True, all() stops at first False.

35. sorted() and .sort()

sorted() works on any iterable. .sort() is list-only.

🟡 Medium (37)¶

1. yield (generators)

Show answer def countdown(n):
while n > 0:
yield n
n -= 1

for x in countdown(3):
print(x) # 3 2 1

Pauses the function and produces a value. Resumes on next iteration. Memory-efficient for large sequences.

3. global / nonlocal

Show answer count = 0
def increment():
global count
count += 1

def outer():
x = 10
def inner():
nonlocal x
x += 1
inner()
print(x) # 11

global refers to module scope; nonlocal refers to enclosing function scope.

5. Walrus operator (:=)

Show answer # Assign and test in one expression
if (n := len("hello")) > 3:
print(f"long: {n} chars") # long: 5 chars

# In a while loop
while (line := input("> ")) != "quit":
print(f"you said: {line}")

# In a comprehension
results = [y for x in data if (y := expensive(x)) > threshold]

Python 3.8+. Use sparingly — readability first.

6. match / case (structural pattern matching)

Show answer def handle(command):
match command.split():
case ["quit"]:
return "bye"
case ["go", direction]:
return f"going {direction}"
case ["pick", "up", item]:
return f"picked up {item}"
case _:
return "unknown"

handle("go north") # "going north"
handle("pick up key") # "picked up key"

Python 3.10+. Matches structure, not just values.

7. Decorator

Show answer def log_calls(fn):
def wrapper(*args, **kwargs):
print(f"calling {fn.__name__}")
return fn(*args, **kwargs)
return wrapper

@log_calls
def add(a, b):
return a + b

add(1, 2) # prints "calling add", returns 3

@decorator is syntactic sugar for: add = log_calls(add)

8. Closure

The inner function captures variables from the enclosing scope. They persist after the outer function returns.

19. add, eq, lt (operator overloading)

Show answer class Vec:
def __init__(self, x, y):
self.x, self.y = x, y
def __add__(self, other):
return Vec(self.x + other.x, self.y + other.y)
def __eq__(self, other):
return self.x == other.x and self.y == other.y

Vec(1,2) + Vec(3,4) # Vec(4, 6)
Vec(1,2) == Vec(1,2) # True

20. super()

Show answer class Base:
def __init__(self, x):
self.x = x

class Child(Base):
def __init__(self, x, y):
super().__init__(x)
self.y = y

c = Child(1, 2)
print(c.x, c.y) # 1 2

Delegates to the next class in the MRO. Always use super() in __init__ for cooperative inheritance.

21. async / await

async def fetch(url):

32. multiprocessing

Show answer from concurrent.futures import ProcessPoolExecutor

def crunch(n):
return sum(i*i for i in range(n))

with ProcessPoolExecutor(max_workers=4) as pool:
results = list(pool.map(crunch, [10**6]*4))

Bypasses the GIL — true parallelism for CPU-bound work. Each worker is a separate process.
