## Objective
apt-get install and cleanup must be in the same RUN layer to reduce image size

## Hint 1
Each RUN creates a new layer. Deleting files in a later layer doesn't reduce image size.

## Hint 2
Combine apt-get update, install, and cleanup in a single RUN with &&.

## Hint 3
Use: RUN apt-get update && apt-get install -y curl wget && rm -rf /var/lib/apt/lists/*
