## Objective
Fix the image reference so the pod can start successfully

## Hint 1
🔍 Observation Hint:

Run `kubectl describe pod web-app -n k8squest` and look at the Events section at the bottom.

You'll see messages about pulling an image. What error do you see?

## Hint 2
🧭 Direction Hint:

The error shows "ImagePullBackOff" or "ErrImagePull". This means Kubernetes can't find the container image you specified.

Check the image name and tag in the pod specification. Does that image tag actually exist in Docker Hub?

Try: `kubectl get pod web-app -n k8squest -o yaml | grep image:`

## Hint 3
💡 Near-Solution Hint:

The image tag "nonexistent-tag-xyz-123" doesn't exist. You need to change it to a valid tag.

Steps to fix:
1. Delete the broken pod: `kubectl delete pod web-app -n k8squest`
2. Edit broken.yaml and change the image to: nginx:latest
3. Apply: `kubectl apply -f broken.yaml`
4. Verify: `kubectl get pod web-app -n k8squest`
