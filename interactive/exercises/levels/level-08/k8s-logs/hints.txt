## Objective
Find and fix the configuration issue causing the application to fail silently

## Hint 1
🔍 Observation Hint:

Check the pod status: `kubectl get pod database-app -n k8squest`

Look at the RESTARTS column. Is it restarting repeatedly?

Now check the logs: `kubectl logs database-app -n k8squest`

What error do you see?

## Hint 2
🧭 Direction Hint:

The logs show an error about a required environment variable:
"Error: Database is uninitialized and superuser password is not specified."

PostgreSQL requires the POSTGRES_PASSWORD environment variable to be set for security.

You need to add this environment variable to the pod specification.

## Hint 3
💡 Near-Solution Hint:

Steps to fix:
1. Delete the pod: `kubectl delete pod database-app -n k8squest`
2. Edit broken.yaml and add the environment variable:
   ```yaml
   env:
   - name: POSTGRES_PASSWORD
     value: "mysecretpassword"
   ```
3. Apply: `kubectl apply -f broken.yaml`
4. Verify: `kubectl logs database-app -n k8squest`

You should see "database system is ready to accept connections"!
