## Objective
Fix the playbook to use the command module instead of shell when no shell features are needed

## Hint 1
Some tasks use shell module when they don't need shell features, and vice versa.

## Hint 2
The shell module should only be used when you need pipes, redirects, or shell builtins.

## Hint 3
Use command for 'uptime' and 'free -m', use shell for 'ps aux | grep nginx' (it has a pipe).
