## Objective
Fix the playbook to use the default filter so undefined variables don't cause errors

## Hint 1
The playbook fails when variables aren't provided - they need fallback values.

## Hint 2
Use Jinja2 default filter to provide fallback values for undefined variables.

## Hint 3
Add '| default(value)' to each variable, e.g., '{{ server_port | default(8080) }}'.
