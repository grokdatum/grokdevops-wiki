## Objective
Fix the service so it routes traffic to the backend pods

## Hint 1
🔍 Observation Hint:

Check the service details: `kubectl describe svc backend-service -n k8squest`

Look at the "Endpoints" field. Is it empty? That means no pods match the service selector!

Now check the pod labels: `kubectl get pod backend-pod -n k8squest --show-labels`

Compare the pod's labels with the service's selector.

## Hint 2
🧭 Direction Hint:

The problem is with the service selector!

The service is looking for pods with label `app: backend-app`, but the pod has `app: backend`.

You need to either:
1. Change the service selector to match the pod labels, OR
2. Change the pod labels to match the service selector

Option 1 is easier - just edit the service!

## Hint 3
✅ Solution Hint:

Fix the service selector:

```bash
kubectl delete svc backend-service -n k8squest
kubectl apply -f solution.yaml -n k8squest
```

Or edit it directly:
```bash
kubectl edit svc backend-service -n k8squest
```

Change the selector from:
```yaml
selector:
  app: backend-app  # Wrong
  tier: api
```

To:
```yaml
selector:
  app: backend  # Correct - matches pod label
  tier: api
```

Then verify endpoints appear:
```bash
kubectl get endpoints backend-service -n k8squest
```
