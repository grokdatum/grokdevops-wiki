## Objective
Fix the dynamic inventory configuration so the output format matches Ansible's expected JSON structure

## Hint 1
Ansible can't parse the dynamic inventory output - groups are formatted incorrectly.

## Hint 2
In the JSON/YAML inventory format, each group needs a 'hosts' key containing the host list.

## Hint 3
Wrap host lists under a 'hosts' key: 'webservers: hosts: [web1, web2]' instead of 'webservers: [web1, web2]'.
