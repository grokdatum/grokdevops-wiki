## Objective
nginx reverse proxy must use the correct service name and port for upstream

## Hint 1
Each container has its own network namespace - 127.0.0.1 is itself.

## Hint 2
In Docker networks, use the service name to reach other containers.

## Hint 3
Change proxy_pass http://127.0.0.1:5000 to proxy_pass http://app:5000.
