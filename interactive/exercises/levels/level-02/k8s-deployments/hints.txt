## Objective
Deployment must have available replicas

## Hint 1
The deployment exists, but something's off. Check how many pods are supposed to be running.

## Hint 2
Use `kubectl get deployment web -n k8squest` - notice the READY column. How many replicas are configured vs how many should be running?

## Hint 3
The deployment has `replicas: 0` which means no pods are running! Scale it up with: `kubectl scale deployment web --replicas=1 -n k8squest` (or edit the deployment and set replicas to a number greater than 0)
