## Objective
RUN instruction must use correct shell syntax to install packages

## Hint 1
There are two forms of RUN: shell form and exec form.

## Hint 2
Shell commands with && need the shell form (no brackets), not exec form.

## Hint 3
Change RUN [apt-get update && apt-get install -y curl] to RUN apt-get update && apt-get install -y curl
