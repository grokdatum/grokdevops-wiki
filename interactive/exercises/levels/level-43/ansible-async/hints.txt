## Objective
Fix the async task's poll value so it runs as a fire-and-forget task

## Hint 1
The backup task blocks execution - other tasks wait for it to complete.

## Hint 2
For fire-and-forget async tasks, the poll value must be set to a specific value.

## Hint 3
Change 'poll: 10' to 'poll: 0' so Ansible doesn't wait for the task to finish.
