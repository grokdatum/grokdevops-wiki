## Objective
Fix the script so the variable set inside a loop is visible after the loop

## Hint 1
Where does the while loop actually execute when you pipe into it?

## Hint 2
Piping into a loop creates a subshell; variables set inside are lost.

## Hint 3
Use a here-string: while read line; do ... done <<< "$(echo -e ...)" to avoid the subshell.
