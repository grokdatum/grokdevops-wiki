## Objective
Fix the NodePort service configuration to enable external access

## Hint 1
🔍 Observation Hint:

Check the service details: `kubectl get svc web-nodeport -n k8squest`

You'll see a NodePort assigned (random port in 30000-32767 range).

The problem? It's random! You need to specify an explicit NodePort for predictable access.

Look at the service YAML - is nodePort specified in the ports section?

## Hint 2
🧭 Direction Hint:

NodePort services expose pods on a static port on each node.

Three ports are involved:
- **targetPort**: Container port (80)
- **port**: Service ClusterIP port (80)
- **nodePort**: External access port (needs to be 30080)

You need to add `nodePort: 30080` to the service spec!

## Hint 3
✅ Solution Hint:

Edit the service to add explicit NodePort:

```bash
kubectl edit svc web-nodeport -n k8squest
```

Or delete and reapply:
```bash
kubectl delete svc web-nodeport -n k8squest
kubectl apply -f solution.yaml -n k8squest
```

Add this to the ports section:
```yaml
ports:
- protocol: TCP
  port: 80
  targetPort: 80
  nodePort: 30080  # Add this line!
```

Valid NodePort range: 30000-32767
