## Hint 2
# 💡 HINT 2: Taints & Tolerations

## What Are Taints?

Taints repel pods from nodes (unless pods tolerate the taint).

```bash
kubectl taint nodes <node> key=value:Effect
```

## Taint Effects

- **NoSchedule**: Don't schedule new pods
- **PreferNoSchedule**: Try not to schedule (soft)
- **NoExecute**: Don't schedule + evict existing pods

## What Are Tolerations?

Tolerations allow pods to schedule on tainted nodes.

```yaml
tolerations:
- key: "dedicated"
  operator: "Equal"
  value: "gpu"
  effect: "NoSchedule"
```

## Your Situation

**Node taint:**
```
dedicated=gpu:NoSchedule
```

**Pod needs:**
```yaml
tolerations:
- key: "dedicated"  # Match key
  value: "gpu"  # Match value
  effect: "NoSchedule"  # Match effect
  operator: "Equal"  # Exact match
```

## Hint 3
# 💡 HINT 3: Complete Solution

## Add Toleration to Pod

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: regular-app
  namespace: k8squest
spec:
  containers:
  - name: app
    image: nginx:latest
  tolerations:  # ✅ Add this!
  - key: "dedicated"  # ✅ Matches taint key
    operator: "Equal"
    value: "gpu"  # ✅ Matches taint value
    effect: "NoSchedule"  # ✅ Matches taint effect
```

## Alternative: Tolerate Any Value

```yaml
tolerations:
- key: "dedicated"
  operator: "Exists"  # Any value
  effect: "NoSchedule"
```

## Apply and Verify

```bash
# Ensure node is tainted
kubectl taint nodes kind-control-plane dedicated=gpu:NoSchedule --overwrite

# Apply solution
kubectl apply -f solution.yaml

# Verify
kubectl get pod regular-app -n k8squest
# Should be Running

# Run validation
./validate.sh
```

## Key Points

1. **Taint = repel** pods
2. **Toleration = allow** scheduling
3. All parts must match: key, value, effect
4. operator: "Equal" (exact) or "Exists" (any value)
