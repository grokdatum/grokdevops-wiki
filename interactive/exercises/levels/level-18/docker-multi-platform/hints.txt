## Objective
Let the build target select the image platform instead of hardcoding an architecture

## Hint 1
Docker uses the target platform from the build request for `FROM` by default.

## Hint 2
Hardcoding any one architecture makes this Dockerfile unsuitable for a multi-platform build.

## Hint 3
Remove the `--platform=linux/s390x` override. Select targets with the build command, for example `docker buildx build --platform linux/amd64,linux/arm64 ...`.
