## Objective
Binary for scratch image must be statically compiled with CGO disabled

## Hint 1
Scratch images have no C library. The binary must be fully static.

## Hint 2
Go uses CGO by default which links against the system C library.

## Hint 3
Add CGO_ENABLED=0 before go build: RUN CGO_ENABLED=0 go build -o myapp main.go
