Schema¶

The enhanced arc schema adds 3 columns to the standard 7-column flashcard format (backwards-compatible):

id  category    difficulty  tags    question    answer  source_path arc_id  arc_position    prerequisite_card_id

Standard columns (1-7)¶

Column Description
id Unique card identifier (format: arc-XXX-NNN)
category Domain category (e.g., networking, kubernetes, security)
difficulty easy, medium, or hard
tags Comma-separated tags including the arc ID
question The question text (narrative, references previous card context)
answer Technically precise answer (2-4 sentences)
source_path Path to the relevant topic pack directory

Arc-specific columns (8-10)¶

Column Description
arc_id Unique identifier for the story arc (e.g., arc-packet-journey)
arc_position Integer position in the arc (1, 2, 3, ...)
prerequisite_card_id Card ID that should be resurfaced if this card is answered incorrectly. Empty for the first card in each arc.

Design Principles¶

  • Narrative flow: Each card's question references or builds on the previous card's answer, creating a continuous story.
  • Progressive difficulty: Cards start easy and increase to hard within each arc.
  • Cross-domain: Every arc crosses at least 2 topic packs, showing how concepts connect in real operations.
  • Prerequisite chaining: The prerequisite_card_id field links each card to its predecessor. If a card is answered wrong, the spaced repetition system can surface the prerequisite card in the next session.
  • Real-world sequences: Arcs follow temporal (boot sequence), causal (incident cascade), or spatial (packet journey) ordering that mirrors actual operational workflows.

Usage¶

Arc decks are auto-discovered alongside regular flashcard decks in training/interactive/knowledge/data/cards/. The session runner and SM-2 engine process them identically to standard cards.

Study modes¶

  • Full arc study: Review all cards in an arc sequentially to learn the complete narrative.
  • Spaced repetition: Cards are scheduled individually via SM-2. When a card is missed, the prerequisite_card_id can be used to schedule the prior card for review.
  • Mixed study: Arc cards are mixed with regular flashcards in balanced or random sessions.

Filtering¶

Arc cards can be filtered by: - Arc ID: --filter-tag arc-packet-journey to study a specific arc. - Domain: --topic networking picks up arc cards in the networking category. - Difficulty: Standard difficulty filtering applies.
